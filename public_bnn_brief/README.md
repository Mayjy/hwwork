# 离线调度模型 BNN 化：公开技术学习包

这套材料只使用公开论文信息，不包含任何公司模型、数据、代码或实验结果。可以上传到个人 GitHub，再在隔离的公司环境中阅读和补充内部材料。

## 推荐阅读顺序

1. `00_先读这篇_技术地图.md`：先建立全局认识。
2. `01_BiDM通俗精读.md`：理解可学习尺度、TBS 和 SPD。
3. `02_StoMPP通俗精读.md`：理解 STE、渐进二值化和梯度阻断。
4. `03_迁移到调度BNN的判断框架.md`：判断论文机制能否迁移。
5. `04_专家问答与汇报骨架.md`：准备汇报和现场提问。

## 两篇论文

- BiDM: Pushing the Limit of Quantization for Diffusion Models, NeurIPS 2024, arXiv:2412.05926。
- Layerwise Progressive Freezing: A Training Scaffold for Depth-Scalable Binary Networks, arXiv:2606.27759。

## 使用原则

- 论文事实、迁移假设和内部实验结论必须分开表述。
- 不需要把公司实验结果带出公司。
- 在公司内只需把 PPT 或表格中的占位符替换为真实数字。
- 不把内部模型名称、数据、日志、曲线或超参数提交到公开仓库。
