# 从论文到调度 BNN：迁移判断框架

## 1. 不按“方法名字”迁移，按“成立条件”迁移

每个论文方法都应写成四元组：

`观察 -> 机制假设 -> 方法设计 -> 可验证预测`

### Learnable scale

- 观察：不同位置的激活幅值差异大，固定尺度误差明显。
- 假设：幅值失配是二值精度损失的重要来源。
- 方法：引入更细粒度或输入相关的可学习尺度。
- 预测：尺度版本应降低中间特征误差，并改善最终任务指标。

### SPD

- 观察：特征具有局部结构，逐点 L2 对二值学生过难。
- 假设：局部关系比绝对数值更容易且更值得模仿。
- 方法：按有语义的邻域分组，匹配组内关系矩阵。
- 预测：关系蒸馏应优于 naive feature L2，尤其在 W1A1 下。

### StoMPP

- 观察：深层全二值网络随深度训练退化，顺序会影响结果。
- 假设：硬二值激活导致梯度阻断，突然全网二值化加剧失配。
- 方法：从输入到输出逐层、层内渐进地提交为二值。
- 预测：forward 优于 global，更应明显优于 reverse；收益随深度和激活二值化增强。

## 2. 对调度模型先做三张“体检表”

这些检查只需在公司内部完成，不需要带出数据。

### 表 A：幅值失配

按层记录：

- 激活均值、标准差、最大绝对值；
- 不同样本或决策阶段之间的变化；
- 二值前后 cosine similarity / MSE；
- scale 的最终分布和是否饱和。

如果变化很小，复杂动态 scale 的必要性较弱。如果层间或阶段间差异很大，可学习 scale 的正收益更可信。

### 表 B：局部性

先定义调度特征中的邻接关系：

- 同一任务的操作；
- 同一资源上的候选任务；
- 时间窗口邻近事件；
- 图上的邻居节点；
- 同一决策阶段的变量。

然后问：打乱这个邻接顺序会不会破坏模型语义？如果不会，机械 patch 基本没有理论依据。

### 表 C：梯度与深度

按层记录：

- gradient norm；
- sign 前后饱和比例；
- 训练早期和后期的梯度变化；
- forward/global/reverse 三种顺序的训练曲线。

StoMPP 的关键验证不是“forward 比 baseline 高一点”，而是顺序对照是否符合梯度阻断预测。

## 3. 最小但有解释力的实验矩阵

不需要一次做很大的超参数搜索。优先完成能够区分机制的实验。

### Scale

1. Baseline。
2. 固定 per-tensor scale。
3. learnable per-tensor 或 per-channel scale。
4. 如果任务存在阶段变化，再测试 input-conditioned scale。

至少记录主指标、训练稳定性和额外推理开销。

### Distillation

1. 无蒸馏。
2. logits/output distillation。
3. 中间特征 L2。
4. 语义分组的 relation distillation。

如果 3 和 4 都无效，需检查教师是否显著优于学生、层是否对齐、蒸馏梯度是否与主损失冲突。

### Progressive binarization

1. 一开始全量量化 + STE。
2. forward layerwise。
3. global progressive。
4. reverse layerwise。

资源有限时，2/3/4 可以缩短训练做机制诊断；最终性能比较再使用相同预算。

## 4. 如何解释当前大致现象

### 可学习尺度有约 2%-3% 提升

可提出但不能过度断言：

> 该结果与幅值失配假设一致。二值表示保留了符号，但固定尺度不足以适配不同层或样本的动态范围，可学习尺度补偿了部分表示误差。

进一步证据应包括尺度分布、中间特征误差或多个随机种子，而不能仅凭一次最终指标证明机制。

### SPD 效果一般

优先解释顺序：

1. 原论文的二维空间局部性在调度特征中是否存在；
2. patch 划分是否有业务语义；
3. 教师/学生层是否可比；
4. 蒸馏权重是否导致梯度冲突；
5. 是否只是超参数不足。

不要一上来把原因归结为 lambda。

### Layerwise 效果一般

优先检查：

1. 当前到底是 W4A4 还是 W1A1；
2. 是否同时二值化激活；
3. 是否从预训练模型开始；
4. 网络是否足够深；
5. 实现是否真的是 elementwise stochastic mask + soft refresh；
6. 是否有足够 epoch；
7. forward/global/reverse 是否产生论文预测的差异。

如果 reverse 也不比 forward 差，说明当前系统可能没有论文所描述的强梯度阻断，或者实现并未复现该机制。

## 5. 汇报中的证据等级

### 可以说“证明”或“论文表明”

仅用于论文在其公开实验范围内直接展示的结果。

### 应说“与……一致”

当内部现象符合机制，但还没有直接诊断证据时。

### 应说“推测”或“待验证”

当原因只是合理解释，还没有消融或测量支持时。

这个用词层次能显著减少专家追问时的风险。
