# BiDM 通俗精读

## 1. 论文要解决的真正问题

扩散模型需要重复执行许多去噪 timestep。不同 timestep 的输入噪声程度不同，激活范围会显著变化；但相邻 timestep 的高层特征又比较相似。

W1A1 同时丢失权重和激活的大部分信息，对生成模型尤其致命。作者把问题分成两个方向：

- 时间方向：不同 timestep 的激活范围如何适配；相邻 timestep 的相似信息如何复用。
- 空间方向：二值学生无法精细模仿全精度教师时，如何利用图像的局部性提供更容易学习的监督。

对应方法是 TBS 和 SPD。

## 2. 基线二值化

### 权重

论文写成：

`w_b = sigma * sign(w)`

其中 `sigma` 用权重绝对值均值初始化，并参与训练。

直觉：`sign(w)`只告诉我们方向，`sigma`补回这一组权重的大致强度。

### 激活

朴素方法是：

`a_b = sign(a)`

问题是无论原激活是 `0.01` 还是 `20`，最后都只是 `+1`。动态范围完全消失。

## 3. 可学习尺度：你当前最值得讲清楚的部分

### 从固定尺度到动态尺度

XNOR++ 使用可训练的 `K`：

`a_b = K * sign(a)`

但训练结束后 `K` 对所有样本或 timestep 基本是固定的。扩散模型在不同 timestep 的激活范围变化很大，一个固定 K 很难全部适配。

XNOR 的思路更动态。它先根据当前输入计算局部平均幅值 `A`，再通过一个固定的均值滤波核 `k` 得到空间尺度：

`I * W ≈ binary_conv(sign(I), sign(W)) * (A * k * alpha)`

这里：

- `binary_conv(...)` 是真正便宜的二值卷积；
- `A` 是当前输入激活在通道方向的平均绝对幅值；
- `k` 是一个很小的二维滤波核；
- `alpha` 是权重的平均绝对幅值。

因为 A 由当前输入计算，所以它能随 timestep 改变。

### BiDM 改了什么

XNOR 中的 `k` 被预先设定成均匀平均核。BiDM 认为不同局部位置、不同模块经过变换后的幅值关系并不等同于简单平均，所以让 `k` 可学习。

直觉可以概括为：

> 不再规定“附近每个位置对尺度的贡献相同”，而是让训练数据决定局部幅值应该怎样组合。

论文附录的单独消融中，仅把 k 改为可学习，LDM-4 的 FID 从 106.62 降到 57.26。这是论文自己的扩散模型结果，不能直接当作调度模型收益。

### 为什么可能迁移到调度模型

只要调度模型存在以下现象，可学习尺度就有一般价值：

- 不同层、样本、节点、变量或时间位置的激活范围差异较大；
- sign 丢掉的幅值信息对最终决策重要；
- 固定 per-layer scale 不足以描述局部差异。

### 迁移时必须问的细节

在汇报里不能只说“加了可学习 scale”。需要明确：

- scale 作用于权重还是激活；
- 是 per-tensor、per-channel、per-token、per-node 还是 per-feature；
- scale 是固定参数，还是由当前输入动态计算；
- 训练时和推理时是否一致；
- 是否引入浮点计算，硬件收益是否仍成立。

## 4. TBS 的跨 timestep 连接

作者观察到相邻去噪步的高维特征相似，于是把相邻 timestep 的特征做可学习融合：

`mixed = (1-alpha) * feature_current + alpha * feature_neighbor`

它的作用不是尺度校准，而是信息补偿：当前二值特征太贫乏，就借用相邻 timestep 中高度相关的信息。

这里的 `alpha` 与前面尺度核 `k` 不是一回事：

- `k`：恢复激活幅值；
- `alpha`：控制跨 timestep 特征融合比例。

迁移到调度模型时，必须先找到真正对应的“邻接维度”。可能是时间步、求解迭代、相邻决策阶段、相邻图节点或相邻层，但不能因为都叫 timestep 就直接照搬。

## 5. SPD 到底在蒸馏什么

### 普通 L2 蒸馏的问题

直接最小化：

`||F_teacher - F_student||^2`

会要求容量很弱的二值学生逐点复现丰富的全精度特征。误差大的位置会主导优化，模型容易得到均匀、平滑但不够有结构的信息。

### SPD 的三步

第一步，将中间特征图切成 `p x p` 个空间 patch。

第二步，在每个 patch 内构造关系/注意力矩阵：

`A = P * P^T`

它关注的不是单个像素数值完全相等，而是 patch 内特征之间的相对关系。

第三步，将教师和学生的 attention 做 L2 归一化后比较，再对所有 patch 求平均。

因此 SPD 可以理解为：

> 不要求二值学生逐像素抄写教师，而要求它在每个局部区域内学到相似的关系结构。

总损失为：

`L = L_task + lambda * average(L_SPD_over_blocks)`

论文默认总公式中写 `lambda=4`，但附录具体实验对不同数据集使用了 `3e-2` 或 `1e-2`。阅读论文时要注意“公式中的默认描述”和“具体实现设置”并不总是同一个数字。

## 6. 为什么 SPD 在调度模型上可能效果一般

SPD 的成功依赖至少三个假设：

1. 特征存在自然的二维空间邻域；
2. 局部关系比逐点特征更值得匹配；
3. 教师和学生的中间层在语义和尺寸上可对齐。

图像卷积 U-Net 天然满足这些条件。一般调度模型未必满足：

- 输入顺序可能只是张量排布，不代表语义邻近；
- 将特征机械切 patch 可能破坏一个完整任务、机器或资源的结构；
- 关键依赖可能是全局资源竞争，而不是局部邻域；
- 主任务损失已经提供足够监督，额外蒸馏可能产生梯度冲突。

因此 SPD 没有提升时，优先检查“patch 的语义是否成立”，而不是直接归因于 lambda 没调好。

## 7. BiDM 的消融应该怎样读

在 LDM-4 / LSUN-Bedrooms / W1A1 上：

| 方法 | FID，越低越好 |
|---|---:|
| Vanilla | 106.62 |
| + TBS | 35.23 |
| + SPD | 40.62 |
| TBS + SPD | 22.74 |

正确结论：两者单独有效，组合后进一步改善。

不能直接推出：TBS 与 SPD 在任何模型上都互补。因为它们的互补性是在扩散 U-Net、图像生成和特定训练设置下得到的。

## 8. 论文局限和现场可质疑点

- 主要结论来自扩散模型，任务特异性较强。
- SPD 依赖图像空间局部性。
- 跨 timestep 连接显著增加训练成本；附录称其会接近翻倍采样计算。
- 理论 OPs 节省不等于真实硬件同倍率加速；论文移动端单卷积测试中，XNOR/BiDM 甚至因尺度相关浮点操作比更简单的二值 baseline 慢。
- 相比 FP32，W1A1 的绝对质量仍有明显差距。

## 9. 一分钟口述版

> BiDM 认为扩散模型全二值化失败有两个特殊原因：不同去噪步的激活范围高度动态，而图像生成又要求丰富的局部结构。TBS 用输入相关且可学习的尺度恢复幅值，并利用相邻 timestep 的特征相似性补偿二值表示；SPD 则不让学生逐点拟合教师，而是在空间 patch 内匹配关系结构。对调度模型而言，可学习尺度对应的是比较普遍的幅值失配问题，迁移基础更强；SPD 是否有效则取决于调度特征中是否存在真正有语义的局部结构。
